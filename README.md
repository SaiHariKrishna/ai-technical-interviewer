# 🤖 AI Technical Interview Agent

A multi-round AI-powered technical interview system designed for hackathons.

## Features
- Round 1: LLM-generated screening MCQs
- Round 2: LLM-generated technical MCQs
- Round 3: Coding challenge evaluated using test cases
- Deterministic evaluation logic
- AI agent orchestration
- Clean Streamlit UI

## Tech Stack
- Python
- Streamlit
- Google Gemini (via google-genai)

## How It Works
- LLM is used only for question generation
- All evaluations are deterministic
- Coding round is verified using hidden test cases

## Deployment
Hosted on Streamlit Community Cloud.

## Disclaimer
This project is a prototype built for hackathon demonstration.
